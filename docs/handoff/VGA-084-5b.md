# VGA-084.5b "Leaves, not balls": brief for the next agent

Written 2026-10-02 by Claude. Read `AGENTS.md` first, at least **The six laws** and
**How to work**. After that, this file is all you need. Everything is in one function:
`buildTrees()` in `src/render/props.js`.

## Where it stands

A street tree's canopy is ten displaced `IcosahedronGeometry` clumps (`CANOPY_CLUMPS`),
so at play distance it reads as a cluster of green balls: VGA-084 calls it out as a toy.
Three instanced meshes (trunks, canopies, branches), three draws. Done means: the canopy
is built from **leaf cards** (small alpha-cut quads, the standard game technique), so the
outline is broken leaves and the sky shows through. It stays three instanced meshes.

## The edit

1. **Leaf texture.** Add `leafTexture()` next to `buildTrees()`. Use a 128×128 canvas,
   cleared transparent, with 26 leaf shapes painted in white: each is an ellipse with radii
   6–11 px by 3–5 px at a random angle, from `mulberry32(78)`. Return a
   `THREE.CanvasTexture` with `colorSpace = THREE.SRGBColorSpace`. White means the
   per-instance leaf colour already set by `setColorAt` tints it, so the palettes keep
   working unchanged.
2. **Leaf cards instead of clumps.** Replace the `canopyGeo` built from `CANOPY_CLUMPS`.
   For each `[x, y, z, r]` in `CANOPY_CLUMPS`, place **18** cards. Each card is a
   `THREE.PlaneGeometry(1.1 * r, 1.1 * r)`, rotated by random X, Y and Z angles, and
   translated to a random point inside the sphere of radius `0.8 * r` around
   `(x, y, z)`. Take the randoms from a separate `mulberry32(79)`, not the `rand` the
   placement loop uses. That gives 180 cards, which is 360 triangles. Merge them with
   `mergeGeometries`. Keep `CANOPY_CLUMPS`: it is now the layout of leaf masses.
3. **Displacement.** In the "Organic displacement" block, drop `canopyGeo` from the list.
   It becomes `for (const [geo, amp] of [[branchGeo, 0.4]])`. Cards are already irregular,
   and jittering their corners would warp the alpha cut.
4. **Keep the sky-occlusion gradient.** The block that writes the `color` attribute from
   `CANOPY_LOW` / `CANOPY_HIGH` works on any geometry. Leave it as it is.
5. **Canopy material.** Add `map: leafTexture(), alphaTest: 0.5, side: THREE.DoubleSide`
   to `canopyMat`. Keep `roughness`, `envMapIntensity` and `vertexColors`. Keep
   `canopies.castShadow = true`; three.js carries `alphaTest` and `map` into the shadow
   pass, so the shadow is leafy too.

Update the comments that describe the canopy as clumps or icosahedra so they describe
leaf cards. Do not touch `treeSpots()`, the placement loop, the palettes, the trunk or the
branches.
