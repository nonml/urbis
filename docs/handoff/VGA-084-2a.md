# VGA-084.2a "Brick and stone": brief for the next agent

Written 2026-10-02 by Claude. Read `AGENTS.md` first, at least **The six laws** and
**How to work**. After that, this file is all you need.

## Where it stands

Every tower is one of three facade kinds (`towerMaterials()` in `src/render/block.js`):
two tints of glass curtain wall and one concrete wall with windows punched through it.
The operator wants "all kinds of styles": a real city mixes brick, stone, concrete and
glass. This slice adds three masonry kinds, built exactly the way the concrete kind is
already built. Choosing *which* building gets *which* kind is the next slice (2b). Here
the existing `idx % kinds.length` rotation spreads them, which is enough to see them.

The operator approved downloading CC0 textures for this (2026-10-02).

## Steps

1. **Pick three Poly Haven textures.** List candidates with
   `curl -s 'https://api.polyhaven.com/assets?type=textures&categories=brick'` and
   `...&categories=wall'`. Choose:
   - **red brick**: an id containing `brick`, red/brown, flat laid courses (not a ruin,
     not painted, not mossy);
   - **pale brick**: an id containing `brick`, cream/yellow/grey;
   - **stone**: dressed stone blocks or smooth limestone/sandstone wall (an id containing
     `stone` or `wall`), flat and regular: no rubble, no cobbles, no rock face.
   Write the three ids and one line on why into your report.
2. **Download the 1k jpg maps.** `curl -s https://api.polyhaven.com/files/<id>` lists the
   URLs. Take `Diffuse` 1k jpg, `nor_gl` 1k jpg and `arm` 1k jpg. Save them as
   `public/assets/<id>/Diffuse.jpg`, `nor_gl.jpg` and `arm.jpg`, the same names as
   `public/assets/concrete_wall_008/`. Write `info.json` in the same shape as that
   folder's: fill `id`, `name`, `authors` and `source` from
   `https://api.polyhaven.com/info/<id>`. If the network is blocked, stop and report
   BLOCKED. Do not substitute textures from anywhere else.
3. **Scale.** `https://api.polyhaven.com/info/<id>` has `dimensions` in millimetres
   (width first). The facade UVs repeat every `FACADE_TILE` = 11 m
   (`src/render/materials.js`), so the repeat is
   `r = Math.round(11 / (dimensions[0] / 1000))`. A 2 m brick sheet gives 6. Write each
   `r` in your report.
4. **Three new kinds.** In `towerMaterials()`, next to the `concrete` line, load each set
   with `loadPolyHavenMaps(texLoader, maxAniso, '<id>', r, r)`. Append three entries to
   `kinds`, after the concrete one:

   ```js
   concreteFacadeMaterial(redBrick, nightMaps.emission, 0x8a7a72),
   concreteFacadeMaterial(paleBrick, nightMaps.emission, 0x8c8880),
   concreteFacadeMaterial(stone, nightMaps.emission, 0x86837d),
   ```

   `concreteFacadeMaterial` already punches the lit windows through any wall texture. Do
   not change it. Update the comment above `towerMaterials`'s caller that says "Three
   facade architectures" so it lists six.
5. Credits: one line per folder in `public/assets/CREDITS.md`, like the
   `Poly Haven Concrete Wall 008` line: name, CC0, URL, and "tower facade (VGA-084.2a)".
