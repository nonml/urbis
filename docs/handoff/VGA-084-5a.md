## Where it stands

The mountain ranges are 21 six-sided, flat-shaded `ConeGeometry` cones with a white cone
on top of each (VGA-084: "the pale spikes in city view"). Two meshes, two draws. Done
means: one smooth terrain mesh per scene, peaks in the same places, snow by height and
slope, no cone anywhere, and one draw instead of two.

## The edit

Replace the body of `buildMountains()`. Keep its name, its export and its return type
(a `THREE.Group`). Keep `mulberry32(133)`.

1. **Keep the peak layout.** Keep `ridge(cx, cz, n, alongX)` and its two calls exactly,
   including the order of every `rand()` call, so the peaks land where the cones were.
   Instead of building cones, push `{ px, pz, r, h }` into a `peaks` array. Peak heights
   stay `h` (60–110).
2. **One height function.** Write `mountainHeight(x, z)`: for each peak,
   `t = distance((x, z), (px, pz)) / r`; if `t < 1`, its contribution is
   `h * (1 - t) ** 1.6`. Take the **max** over peaks, not the sum. Then add ridged
   detail: `+ 7 * n * (base / 110)`, where `base` is that max and `n` is a seeded value
   noise in `[-1, 1]` at 1/18 m frequency plus half of it at 1/7 m. Write a small
   hash-based value noise in this file; do **not** add a package. Return `base + detail - 4`
   (the cones sat 4 m sunk, so their bases were hidden; keep that).
3. **One grid per range, merged.** For each range, take the bounding box of its peaks'
   `px ± r`, `pz ± r`. Clamp the west range so x never goes above `-36`, and the north
   range so z never goes below `88`. Build a `THREE.PlaneGeometry` over that box with
   3 m cells, `rotateX(-Math.PI / 2)`, translate it to the box centre, and set every
   vertex's y to `mountainHeight(x, z)`. Clamp y to at least `-4`. Merge the two grids
   with `mergeGeometries` and call `computeVertexNormals()`.
4. **Colour by height and slope.** Add a `color` attribute. Rock is `0x232c3a`, varied
   ±8% in brightness by the same noise. Snow is `0xdfe8f2`. Snow weight is
   `smoothstep(52, 64, y) * smoothstep(0.45, 0.7, normal.y)`, so steep faces stay rock.
   Lerp rock to snow by that weight.
5. **One material.** `new THREE.MeshStandardMaterial({ vertexColors: true, roughness: 1.0 })`.
   No `flatShading`. Do not set `castShadow` (the cones did not).

Update the file's header comment and `outskirts.js` line 32's mention of "cone bases"
to say "mountain bases" (one word each). Nothing else in `outskirts.js`.
