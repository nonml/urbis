# VGA-084.2c "Rooflines and cornices": brief for the next agent

Written 2026-10-02 by Claude. Read `AGENTS.md` first, at least **The six laws** and
**How to work**. After that, this file is all you need. All edits are in
`emitTower()` in `src/render/block.js`, plus one new helper beside it.

## Where it stands

Since 2b, every avenue row is a continuous wall of glass, concrete, brick and stone
buildings. Each still ends in the same two flat slabs (`caps.push(box(w + 0.4, 0.5, ...))`
at `h`, and `box(w + 0.9, 0.35, ...)` at `topY`). So from the street, and from city view,
every roof is a plain box lid. Real buildings end in a **parapet**, a low wall around the
roof edge, and masonry buildings carry a **cornice**, a stepped ledge just below it.

The operator agreed (2026-10-02): real geometry at the roofline and the lower floors,
flat textured windows above. This slice is the roofline. Everything goes into the
existing `caps` merge, so it costs no draw.

## The edit

1. Add a helper next to `emitTower`. It pushes boxes, nothing else:

```js
// The top of a row building: a parapet wall around the roof edge and, on
// masonry, a two-step cornice under it. Real roofs end in an edge, not a lid.
const PARAPET_H = 1.1;
const PARAPET_T = 0.3;
const MASONRY_KINDS = [3, 4, 5];
function roofline(caps, cx, cz, w, top, d, kind) {
  caps.push(
    box(w, PARAPET_H, PARAPET_T, cx, top + PARAPET_H / 2, cz + d / 2 - PARAPET_T / 2),
    box(w, PARAPET_H, PARAPET_T, cx, top + PARAPET_H / 2, cz - d / 2 + PARAPET_T / 2),
    box(PARAPET_T, PARAPET_H, d - 2 * PARAPET_T, cx + w / 2 - PARAPET_T / 2, top + PARAPET_H / 2, cz),
    box(PARAPET_T, PARAPET_H, d - 2 * PARAPET_T, cx - w / 2 + PARAPET_T / 2, top + PARAPET_H / 2, cz),
    box(w + 0.3, 0.12, d + 0.3, cx, top + PARAPET_H + 0.06, cz),   // coping stone
  );
  if (MASONRY_KINDS.includes(kind)) {
    caps.push(
      box(w + 0.8, 0.45, d + 0.8, cx, top - 0.55, cz),
      box(w + 0.45, 0.25, d + 0.45, cx, top - 0.9, cz),
    );
  }
}
```

2. In `emitTower`, the two roof slabs are
   `caps.push(box(w + 0.4, 0.5, d + 0.4, cx, h + 0.25, cz));` and
   `caps.push(box(w + 0.9, 0.35, d + 0.9, cx, topY + 0.1, cz));`.
   Wrap both in `if (door) { ... } else { ... }`. Keep the two lines exactly as they are
   in the `if` branch. In the `else` branch, call:
   - `roofline(caps, cx, cz, w, h, d, kind);`
   - and, only when the tower has a setback crown (`topY > h`),
     `roofline(caps, cx, cz, w * 0.72, topY, d * 0.72, kind);`. Use the same `0.72` the
     crown is built with; better still, hoist it into a `CROWN` constant used in both
     places.
   `door` is `false` only for the generated rows (see 2b), so the pinned towers, the
   south row and the terminus keep their slabs.
3. The rooftop plant boxes after the slabs stay as they are. They sit inside the
   parapet now, which is where plant belongs.
