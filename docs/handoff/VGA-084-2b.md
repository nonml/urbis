# VGA-084.2b "A street wall": brief for the next agent

Written 2026-10-02 by Claude. Read `AGENTS.md` first, at least **The six laws** and
**How to work**. After that, this file is all you need.

**Start only after VGA-084.2a (brick and stone kinds) is on `main`:** this slice uses
facade kinds 3, 4 and 5. Check with `grep -c concreteFacadeMaterial src/render/block.js`;
it must print at least `4`.

## Where it stands

Each avenue row is one hand-written table, `TOWERS`, copied onto all three avenues. Its
towers are 10–14 m wide on 18–20 m centres, so only 40–52% of each row is a building
wall: the blocks read as pieces on a board. The same row on three avenues is a clone.
Three of the rows also stand on the plaza crossing, and every tower wider than it is deep
pokes onto the walkway (the setback used depth where it meant width).

The operator asked for a street that "looks like a real city", in "all kinds of styles"
(2026-10-02). Done means: every avenue row is a continuous wall of buildings of varied
frontage, height and material, different on every avenue, standing on one building line,
clear of every road, lot and door.

## Numeric pass/fail

`npm run check:overlap` measures all three. When you finish it must print exactly:

| Line | Must read |
|---|---|
| `overlap:` | `0 intersecting pairs` |
| `road:` | `12 towers on a road or walkway`. The 12 left are `SOUTH_TOWERS` and `TERMINUS_TOWERS`. Not this slice. |
| `frontage: worst row` | `98.2%` or more. The main avenue's west row keeps a 1.9 m sliver south of the roof tower. |

Set the ratchets in `scripts/check_overlap.mjs` to what it asks: `MAX_ROAD = 12` and
`MIN_FRONTAGE` to the value it prints. Change nothing else in that file. Its `KEEP_OUT`
table is the source of truth for the gaps, and yours must match it.

Also: `GATE_PORT=4673 npm run gate` is fully green, and its `draws:` line is no higher
than on `main` (rows merge into the facade kinds that already exist, so expect +0).

## The edits

### 1. `src/render/block.js`: replace `TOWERS` with a generated street wall

Delete the `TOWERS` table and its comment. In its place:

```js
// Shaft face of every avenue row, metres from the avenue centre-line. The
// podium stands 0.6 m proud of it, so the shopfronts meet the walkway edge.
const BUILD_LINE = 7.5;
// The two main-avenue towers the interiors are built into, kept exactly:
// [side, z, w, h, d]. The roof is idx 0 and the noodle bar idx 1, as before,
// so their facades and shopfronts do not change.
const PINNED_TOWERS = [[-1, -48, 12, 34, 10], [-1, -14, 14, 44, 11]];
// Where an avenue row may stand: south of the plaza crossing and north of it.
const ROW_RUNS = [[-55.5, 33.5], [46.5, 97]];
// A gap shorter than this stays open: narrower than any real building.
const MIN_RUN = 6;
// [avenue x, side, z0, z1]: stretches of a row that stay open.
const KEEP_OUT = [ ...copy the table from scripts/check_overlap.mjs exactly... ];
const STREET_WALL_SEED = 2084;
```

Copy `KEEP_OUT` from the checker, comments included.

Add `styleFor(ax, z)`. It says what a stretch of street is built from. `kinds` index
`mats.kinds`: 0 and 1 are glass, 2 concrete, 3 red brick, 4 pale brick, 5 stone.
`front` is the podium frontage range in metres, and `h` the height range.

```js
function styleFor(ax, z) {
  if (ax === 0 && z < 40) return { kinds: [0, 1, 2, 5], h: [28, 52], front: [12, 20] }; // downtown core
  if (ax === 0) return { kinds: [2, 3, 5], h: [18, 36], front: [9, 16] };               // north of the plaza
  if (ax > 0) return { kinds: [1, 2, 4, 5], h: [18, 40], front: [9, 16] };              // east avenue
  return { kinds: [3, 4, 2], h: [12, 26], front: [7, 13] };                             // west: older brick
}
```

Add `streetWall(ax, side, rand)`. It returns `[{ z, d, w, h, kind }]`:

1. `runs` = `ROW_RUNS`, minus every `KEEP_OUT` entry for this `ax` and `side`, minus the
   podium z-extent (`z ± (d + 1.2) / 2`) of every `PINNED_TOWERS` entry, when
   `ax === AVENUE_X[0]` and `side` matches. Write one small `subtract(runs, [a, b])`
   helper for this.
2. For each run `[r0, r1]`, set `at = r0`. While `r1 - at >= MIN_RUN`:
   - `st = styleFor(ax, at)`
   - `p = st.front[0] + rand() * (st.front[1] - st.front[0])`; if `r1 - at - p < MIN_RUN`,
     set `p = r1 - at` (the last building takes the rest, so the run ends on a wall)
   - `h = Math.round(st.h[0] + rand() * (st.h[1] - st.h[0]))`
   - `kind = st.kinds[Math.floor(rand() * st.kinds.length)]`
   - `w = 10 + rand() * 2`
   - push `{ z: at + p / 2, d: p - 1.2, w, h, kind }`, then `at += p`

   Call `rand()` in exactly that order. The podium is `d + 1.2` deep, so neighbours share
   a party wall with no gap and no overlap.

### 2. `src/render/block.js`: `emitTower()` and the emit loop

- The signature becomes
  `emitTower(cx, cz, w, h, d, idx, face, name, kind = idx % facades.length, door = true)`,
  and the shaft line becomes `const shaft = facades[kind][zone];`.
- Wrap the door recess and its canopy (the two `caps.push` lines after
  `const faceZ = ...`) in `if (door) { ... }`. A row building's +Z face is a party wall,
  where a door would be buried in its neighbour.
- Replace the `for (const ax of AVENUE_X) { TOWERS.forEach(...) }` loop with:

```js
let idx = 0;
PINNED_TOWERS.forEach(([side, z, w, h, d], i) => {
  emitTower(AVENUE_X[0] + side * (BUILD_LINE + w / 2), z, w, h, d, idx++, [-side, 0], `PINNED_TOWERS[${i}]`);
});
const rand = mulberry32(STREET_WALL_SEED);
for (const ax of AVENUE_X) {
  for (const side of [-1, 1]) {
    streetWall(ax, side, rand).forEach((b, i) => {
      emitTower(ax + side * (BUILD_LINE + b.w / 2), b.z, b.w, b.h, b.d, idx++, [-side, 0],
        `ROW[x=${ax} side ${side}][${i}]`, b.kind, false);
    });
  }
}
```

  Keep the `SOUTH_TOWERS` and `TERMINUS_TOWERS` loops after it, unchanged. Import
  `mulberry32` from `'../sim/rng.js'`. Note that the setback is now `BUILD_LINE + w / 2`:
  `w` is the box's x size, so this is the axis fix.
