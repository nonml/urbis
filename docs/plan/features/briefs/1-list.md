## How to work: read this first

The list is far too long to plan in your head. If you think it all through before
writing, you run out of output and lose everything. So:

1. Your first action is a tool call that writes the file with its `#` heading and every
   `##` category heading. No research and no long thinking before it.
2. Then one category at a time: think about that category only, append its rows to the
   file with a tool call, then go to the next.
3. Never draft more than one category before writing it.

## What counts as a feature

Anything a player can do, see, hear, use, buy, choose or set in the game, and every
system that runs in the world whether the player touches it or not. One row each.
Split compound things. "Police" is not one row: each wanted level, what raises heat,
each kind of unit, each way to lose them, what happens when caught are separate rows.
"Roads" is not one row: each road type, each road tool, each junction control are rows.

## Format

One markdown file, headed `# <title>: every feature`, then one `##` section per category
below, in that order, each a table:

| ID | Feature | What the player does or sees | Where |
|---|---|---|---|

- ID: `<PREFIX>-<category number, 2 digits>-<row number, 3 digits>`, e.g. `GTA-03-012`.
- Feature: a short name, 2-8 words.
- What the player does or sees: one plain sentence, concrete. Name the control, the
  number, the in-game name where you know it.
- Where: the entry and the DLC or update it came in (the codes are in your scope below).
  If you are not sure the feature exists, write `(unsure)` after the code.

## Rules

1. Exhaustive. There is no quota, but a category with fewer than 10 rows is probably
   incomplete: think again before leaving it. Expect several hundred rows in all.
2. Real features only. Never invent one. When unsure, mark it `(unsure)` or leave it out.
3. Each feature once, in the category it fits best. No duplicates.
4. Plain words. No marketing words ("immersive", "dynamic", "rich", "seamless").
5. Describe this game only. Do not compare it to other games and do not suggest anything.
6. You may check the game's wiki with a web fetch tool if you have one, at most 15
   fetches. Your own knowledge comes first.
7. Work in passes, appending to the file as you go (never one giant write):
   a. write the heading and every category heading;
   b. fill each category in turn;
   c. re-read the whole file and add what is missing. Check against: every menu and
      setting, every button and meter on the HUD, every icon on the map legend, every
      vehicle or building class, every activity, every DLC's and every update's additions.
8. Do not read, open or search any other file or directory. Write only your one file.
9. When done, print the number of rows per category and the total, and stop.
