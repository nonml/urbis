### What went well

- **Architecture boundary held**: zero `three` imports in `src/sim/` throughout all 4 quarters
- **RNG discipline**: `Math.random()` check gate caught violations early; zero in production code
- **Pattern consistency**: weapon, hack, and HUD patterns remained stable — new content slots into existing shapes
- **Incremental delivery**: every Q4 feature built on Q3 physics (ragdoll knockback uses Rapier impulse, vehicle damage uses physics colliders)

### What could improve

- **No dedicated wave encounter system**: police escalation acts as emergent wave combat but there's no authored 5-wave scenario for structured testing
- **Test coverage skews smoke-level**: 276 passing tests are mostly unit/smoke; integration scenarios (multi-system combat flow) are thin
- **Content volume low**: combat systems are deep but content (enemy types, encounter variety) hasn't scaled yet — Q5 addresses this

### Risks entering Year 2

- **Q5 content volume** (50 buildings, 30 vehicles, 20 NPCs, 15 quests) is a quantity challenge — needs validator-driven pipeline
- **Hacking depth (Q6)** requires camera network and hack chains — new subsystems, not extensions of existing ones
- **Narrative (Q7)** introduces TTS and cinematic cameras — external dependencies and new render-path code

### Decision log

- Behavior tree library kept minimal (5 node types) — complexity lives in behavior definitions, not the engine
- Vehicle damage uses seeded RNG for deformation — determinism preserved for save/load
- Police helicopter is a sim-only entity with render overlay — no physics body, avoids Rapier overhead
