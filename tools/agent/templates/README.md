# Agent Content Templates

Populated in Q5 (Content Engine). Each template defines the schema, generator prompt, and validator for a content type:

- `content_building.json` — building model + metadata template
- `content_vehicle.json` — vehicle model + metadata template
- `content_weapon.json` — weapon definition template
- `content_quest.json` — quest definition template
- `content_npc_archetype.json` — NPC archetype template

These are stubbed here for Q1. The curator auto-generates filled templates in Q5.
