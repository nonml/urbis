# Project Plan (current → 1.0.0 → post‑1.0 roadmap)

This folder contains milestone-by-milestone tickets to take the repo from the **current prototype state** to a **1.0.0 playable build**.

## How to use
- Work milestone-by-milestone in order: **A → B → C → D → E**
- Each ticket has:
  - **Objective** (what/why)
  - **Design** (how it should work)
  - **Specs** (data shapes + constraints + file targets)
  - **Implementation details** (step-by-step)
  - **Acceptance criteria** (what must be true)
  - **Definition of Done** (DoD) (how we consider it “shippable”)

## Repo assumptions
- Tech: vanilla JS + ES modules, Three.js via ESM CDN
- Runs via local static server (see `README.md`).

## Milestones
- **Milestone A:** Stabilize foundations + deterministic sim + perf guardrails
- **Milestone B:** City generation (districts/roads/parcels) + third-person exploration loop
- **Milestone C:** Quest/storylet system + “Case File” side-stories (Watch Dogs vibe)
- **Milestone D:** Rival AI + progression + win/lose conditions + balance
- **Milestone E:** Polish, QA, packaging, and 1.0.0 release checklist

- **Milestone F:** Post‑launch 1.1.0 (Content + QoL + Stability)
- **Milestone G:** 1.2.0 (Modding + Creator Tools + Sharing)
- **Milestone H:** 1.3.0 (Challenges + Photo + Replay)
