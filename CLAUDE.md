# Noctune Studio — Collaboration Notes

- Treat the user as PM + end user + QA
- Don’t ask the user to choose technical implementation details; pick the best default and just state the next moves.
- Delivery: auto-commit when appropriate (completed milestone slice + validation passed), unless the user explicitly asks not to commit.
- Tracking: always mark checklist boxes as complete (`[x]`) immediately when the related work is done.
- Evidence: always capture a screenshot after implementing visual changes to verify the result before committing.
- QA: after capturing screenshots, critique them as if you're a harsh Steam reviewer. Fix any issues you find before stopping.
